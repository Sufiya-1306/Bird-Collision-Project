Dataset Architecture & Reproduction Pipeline

Comprehensive documentation of recent USA data sources (2021–2025) and ETL steps

FAA Wildlife Strike Database (2021–2025)

Contains 11,954 collision records across Colorado, Illinois, and New York. Features flight phase, flight altitude, engine count, wildlife size, and sky conditions. Pre-collision variables only are used for model training to prevent outcome leakage.

USWTDB Wind Turbine Database

Contains 8,533 operational wind turbines in NY, IL, and CO. Great-circle Haversine distances are computed from each flight's origin/destination airport to the nearest wind farm cluster, providing a critical hazard proximity feature.

NOAA ASOS/METAR Weather Data (2021–2025)

187,365 hourly observations from primary representative airport weather stations: KDEN (Denver, CO), KORD (Chicago, IL), and KJFK (New York, NY). Aggregated to daily station averages for temperature, wind speed, visibility, precipitation, and barometric pressure.

GBIF Global Bird Occurrences (11.6 GB)

55,344,878 occurrence observations streamed in chunks of 500,000 rows. Filtered for target states, valid coordinates, and years 2021–2025. Created reproducible monthly migration density indices (0.0–1.0) and peak migration flags.

Pipeline Reproduction Commands

All data processing and training steps are automated and fully reproducible:

# Step 1: Clean 4 core processed datasets

py -3.11 scripts/01_clean_data.py

# Step 2: Stream process 11.6 GB migration dataset in chunks

py -3.11 scripts/02_process_migration_streaming.py

# Step 3: Merge and engineer ML dataset with risk target

py -3.11 scripts/03_build_final_ml_dataset.py

# Step 4: Train all 9 machine learning models with 5-fold CV

py -3.11 scripts/04_train_all_models.py

# Step 5: Generate comparison metrics and charts

py -3.11 scripts/05_evaluate_and_compare.py
